# hollowbit.dev

The website of Hollowbit, a small studio making free, offline, open-source tools: [Fileshaper](https://fileshaper.app) and [Captionshaper](https://captionshaper.app).

Plain static HTML, CSS and JavaScript. No build step, no trackers, no third-party requests. Served by GitHub Pages at https://hollowbit.dev.

- `node scripts/shot.mjs` renders desktop and mobile screenshots into `.impeccable/review/`
- `node scripts/assets.mjs` re-renders the favicon PNG, touch icon and share image
