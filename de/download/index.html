Fileshaper

Videos für Discord komprimieren, iPhone-Fotos umwandeln, PDFs zusammenfügen und unterschreiben. Ein Werkzeugkasten, komplett offline.

v1.2.0
MacDein Computer

macOS 12 Monterey oder neuer

Für Apple Silicon laden Intel-Mac? Nimm stattdessen diese
WindowsDein Computer

Windows 10 oder 11, 64 Bit

Für Windows laden 64-Bit-Installer (.exe)
Zum ersten Mal öffnen

Fileshaper ist noch nicht mit einem kostenpflichtigen Apple- oder Microsoft-Zertifikat signiert, deshalb fragt dein Computer einmal nach. Es ist sicher, und jede Zeile Code ist öffentlich.

Mac

  1. Öffne die .dmg und zieh Fileshaper in Programme.
  2. Rechtsklick auf Fileshaper in Programme und Öffnen wählen.
  3. Auf Öffnen klicken. Blockiert macOS es weiter, geh zu Systemeinstellungen, Datenschutz & Sicherheit, und klick auf Trotzdem öffnen.

Windows

  1. Starte das geladene Installationsprogramm.
  2. Siehst du „Der Computer wurde durch Windows geschützt“, klick auf Weitere Informationen.
  3. Klick auf Trotzdem ausführen. Das musst du nur einmal tun.
  • Etwa 350 MB nach der Installation
  • 4 GB Arbeitsspeicher oder mehr
  • Internet nur für die optionale Update-Prüfung

Captionshaper

Wortgenaue Untertitel für jedes Video, geschrieben von einem Sprachmodell auf deinem eigenen Computer. SRT, VTT oder eingebrannt.

v1.1.0
MacDein Computer

Apple Silicon (M1 oder neuer), macOS 12 oder neuer

Für Apple Silicon laden Vorerst nur Apple Silicon
WindowsDein Computer

Windows 10 oder 11, 64 Bit

Für Windows laden 64-Bit-Installer (.exe)
Zum ersten Mal öffnen

Captionshaper ist noch nicht mit einem kostenpflichtigen Apple- oder Microsoft-Zertifikat signiert, deshalb fragt dein Computer einmal nach. Es ist sicher, und jede Zeile Code ist öffentlich.

Mac

  1. Öffne die .dmg und zieh Captionshaper in Programme.
  2. Rechtsklick auf Captionshaper, Öffnen wählen, dann auf Öffnen klicken.
  3. Blockiert macOS es weiter, geh zu Systemeinstellungen, Datenschutz & Sicherheit, und klick auf Trotzdem öffnen.

Windows

  1. Starte das Installationsprogramm. Erscheint SmartScreen, klick auf Weitere Informationen und dann auf Trotzdem ausführen.
  2. Fragt Windows nach der Microsoft Visual C++ Runtime, stimm zu. Die Sprach-Engine braucht sie.
  • Sprachmodelle werden einmal geladen, danach läuft alles offline
  • Windows fragt eventuell nach der Microsoft Visual C++ Runtime

Diskshaper

Sieh, was deinen Speicher auffrisst, von Shader-Caches und Steam-Resten bis zu Premiere-Caches und doppelten Fotos. Räum nur auf, was sicher ist, immer in den Papierkorb.

v1.0.0
MacDein Computer

macOS 11 Big Sur oder neuer

Für Apple Silicon laden Intel-Mac? Nimm stattdessen diese
WindowsDein Computer

Windows 10 oder 11, 64 Bit

Für Windows laden 64-Bit-Installer (.exe)
Zum ersten Mal öffnen

Diskshaper ist noch nicht mit einem kostenpflichtigen Apple- oder Microsoft-Zertifikat signiert, deshalb fragt dein Computer einmal nach. Es ist sicher, und jede Zeile Code ist öffentlich.

Mac

  1. Öffne die .dmg und zieh Diskshaper in Programme.
  2. Rechtsklick auf Diskshaper, Öffnen wählen, dann auf Öffnen klicken.
  3. Fragt macOS nach Zugriff auf Schreibtisch, Dokumente oder Downloads, erlaube es, damit Diskshaper dort große Dateien findet.

Windows

  1. Starte das Installationsprogramm. Erscheint SmartScreen, klick auf Weitere Informationen und dann auf Trotzdem ausführen.
  2. Öffne Diskshaper über das Startmenü und drück auf Scannen.
  • Liest nur, bis du auf Aufräumen drückst
  • Alles landet im Papierkorb
  • Online nur für die tägliche Update-Prüfung, abschaltbar

Writeshaper

Text in einer beliebigen App markieren, Tastenkürzel drücken: korrigiert, oder klarer, kürzer, freundlicher oder professioneller. Das Modell läuft auf deinem Computer.

v1.0.0
MacDein Computer

macOS 12 oder neuer

Für Apple Silicon laden Intel-Mac? Nimm stattdessen diese
WindowsDein Computer

Windows 10 oder 11, 64 Bit

Für Windows laden 64-Bit-Installer (.exe)
Zum ersten Mal öffnen

Writeshaper ist noch nicht mit einem kostenpflichtigen Apple- oder Microsoft-Zertifikat signiert, deshalb fragt dein Computer einmal nach. Es ist sicher, und jede Zeile Code ist öffentlich.

Mac

  1. Öffne die .dmg und zieh Writeshaper in den Programme-Ordner.
  2. Rechtsklick auf Writeshaper, Öffnen wählen, dann Öffnen.
  3. Lade das Modell, wenn es fragt, und erlaube Writeshaper unter Datenschutz & Sicherheit → Bedienungshilfen, damit das Kürzel kopieren und einfügen kann.

Windows

  1. Starte den Installer. Wenn SmartScreen erscheint, klick auf Weitere Informationen und dann Trotzdem ausführen.
  2. Öffne Writeshaper, lade das Modell, markiere irgendwo Text und drück Alt + Umschalt + Leertaste.
  • Einmaliges 1,9-GB-Schreibmodell, in der App geladen
  • Dein Text verlässt nie deinen Computer
  • Online nur für den Modell-Download und eine tägliche Update-Prüfung, die du abschalten kannst

Startshaper

Finde heraus, warum dein Computer langsam ist. Sieh jede App, die von selbst startet, was sie ist – in einfachen Worten – und schalte ab, was du nicht brauchst. Alles lässt sich rückgängig machen.

v1.0.0
MacDein Computer

macOS 13 Ventura oder neuer

Für Apple Silicon laden Intel-Mac? Nimm stattdessen diese
WindowsDein Computer

Windows 10 oder 11, 64 Bit

Für Windows laden 64-Bit-Installer (.exe)
Zum ersten Mal öffnen

Startshaper ist noch nicht mit einem kostenpflichtigen Apple- oder Microsoft-Zertifikat signiert, deshalb fragt dein Computer einmal nach. Es ist sicher, und jede Zeile Code ist öffentlich.

Mac

  1. Öffne die .dmg und zieh Startshaper in Programme.
  2. Rechtsklick auf Startshaper, Öffnen wählen, dann Öffnen.
  3. Drück Meinen Mac prüfen. Einträge, die ein Admin-Passwort brauchen, öffnen Systemeinstellungen → Anmeldeobjekte.

Windows

  1. Starte das Installationsprogramm. Bei SmartScreen auf Weitere Informationen und dann Trotzdem ausführen klicken.
  2. Öffne Startshaper und drück Meinen PC prüfen. Für die Startzeit in Sekunden als Administrator ausführen.
  • Liest nur, bis du einen Schalter umlegst
  • Löscht nie etwas, alles lässt sich rückgängig machen
  • Online nur für eine tägliche Update-Prüfung (abschaltbar)
