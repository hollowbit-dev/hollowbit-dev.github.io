Writeshaper

在任何应用中选中文字，按下快捷键，就能修正错误，或让文字更清楚、更简短、更友好、更专业。写作模型在你的电脑上运行。

Mac你的电脑

macOS 12 或更新

下载 Apple Silicon 版 Intel 芯片 Mac？请下载这个
Windows你的电脑

Windows 10 或 11，64 位

下载 Windows 版 64 位安装程序（.exe）
首次打开

Writeshaper 还没有使用付费的 Apple 或 Microsoft 证书签名，所以电脑会询问一次。它是安全的，所有代码都是公开的。

Mac

  1. 打开 .dmg，把 Writeshaper 拖到“应用程序”。
  2. 右键点击 Writeshaper，选择“打开”，再点“打开”。
  3. 按提示下载写作模型，然后在“隐私与安全性 → 辅助功能”中允许 Writeshaper，这样快捷键才能复制和粘贴。

Windows

  1. 运行安装程序。如果出现 SmartScreen，点击“更多信息”，再点“仍要运行”。
  2. 打开 Writeshaper，下载写作模型，在任意位置选中文字后按 Alt + Shift + 空格。
  • 一次性 1.9 GB 写作模型，在应用内下载
  • 你的文字从不离开你的电脑
  • 只在下载模型和每日检查更新时联网（可关闭）

Startshaper

找出电脑变慢的原因。查看每个自动启动的应用，用大白话说明它是什么，关掉不需要的。每项更改都能撤销。

Windows你的电脑

Windows 10 或 11，64 位

下载 Windows 版 64 位安装程序（.exe）
首次打开

Startshaper 还没有使用付费的 Apple 或 Microsoft 证书签名，所以电脑会询问一次。它是安全的，所有代码都是公开的。

Mac

  1. 打开 .dmg，把 Startshaper 拖进“应用程序”。
  2. 右键点按 Startshaper，选择“打开”，再点“打开”。
  3. 点“检查我的 Mac”。需要管理员密码的项目会打开“系统设置 → 登录项”。

Windows

  1. 运行安装程序。如果出现 SmartScreen，点“更多信息”，再点“仍要运行”。
  2. 打开 Startshaper，点“检查我的电脑”。想看开机秒数，请以管理员身份运行。
  • 在你拨动开关之前只读取
  • 从不删除任何东西，每项更改都能撤销
  • 仅为每日检查更新而联网（可关闭）
