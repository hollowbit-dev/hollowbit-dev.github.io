Premier lancement

Fileshaper n’est pas encore signé avec un certificat payant d’Apple ou de Microsoft, donc votre ordinateur demande une fois. C’est sûr, et tout le code est public.

Mac

  1. Ouvrez le .dmg et glissez Fileshaper dans Applications.
  2. Faites un clic droit sur Fileshaper dans Applications et choisissez Ouvrir.
  3. Cliquez sur Ouvrir. Si macOS le bloque encore, allez dans Réglages Système, Confidentialité et sécurité, et cliquez sur Ouvrir quand même.

Windows

  1. Lancez l’installeur téléchargé.
  2. Si vous voyez « Windows a protégé votre ordinateur », cliquez sur Informations complémentaires.
  3. Cliquez sur Exécuter quand même. Vous ne le faites qu’une fois.
  • Environ 350 Mo une fois installé
  • 4 Go de mémoire ou plus
  • Internet seulement pour la vérification facultative des mises à jour

Captionshaper

Des sous-titres calés mot par mot pour n’importe quelle vidéo, écrits par un modèle vocal sur votre propre ordinateur. SRT, VTT ou incrustés.

v1.1.211 novembre 2026
MacVotre ordinateur

Apple Silicon (M1 ou plus récent), macOS 12 ou plus récent

Télécharger pour Apple Silicon Apple Silicon uniquement pour l’instant
WindowsVotre ordinateur

Windows 10 ou 11, 64 bits

Télécharger pour Windows Installeur 64 bits (.exe)
Premier lancement

Captionshaper n’est pas encore signé avec un certificat payant d’Apple ou de Microsoft, donc votre ordinateur demande une fois. C’est sûr, et tout le code est public.

Mac

  1. Ouvrez le .dmg et glissez Captionshaper dans Applications.
  2. Faites un clic droit sur Captionshaper, choisissez Ouvrir, puis cliquez sur Ouvrir.
  3. Si macOS le bloque encore, allez dans Réglages Système, Confidentialité et sécurité, et cliquez sur Ouvrir quand même.

Windows

  1. Lancez l’installeur. Si SmartScreen apparaît, cliquez sur Informations complémentaires, puis Exécuter quand même.
  2. Si Windows demande d’installer le runtime Microsoft Visual C++, acceptez. Le moteur vocal en a besoin.
  • Les modèles vocaux se téléchargent une fois, puis tout fonctionne hors ligne
  • Windows peut demander d’installer le runtime Microsoft Visual C++

Diskshaper

Voyez ce qui dévore votre stockage, des caches de shaders et restes Steam aux caches Premiere et photos en double. Nettoyez seulement ce qui est sûr, toujours vers la Corbeille.

v1.0.211 novembre 2026
MacVotre ordinateur

macOS 11 Big Sur ou plus récent

Télécharger pour Apple Silicon Mac Intel ? Prenez plutôt celui-ci
WindowsVotre ordinateur

Windows 10 ou 11, 64 bits

Télécharger pour Windows Installeur 64 bits (.exe)
Premier lancement

Diskshaper n’est pas encore signé avec un certificat payant d’Apple ou de Microsoft, donc votre ordinateur demande une fois. C’est sûr, et tout le code est public.

Mac

  1. Ouvrez le .dmg et glissez Diskshaper dans Applications.
  2. Faites un clic droit sur Diskshaper, choisissez Ouvrir, puis cliquez sur Ouvrir.
  3. Si macOS demande l’accès au Bureau, aux Documents ou aux Téléchargements, autorisez-le pour que Diskshaper y trouve les gros fichiers.

Windows

  1. Lancez l’installeur. Si SmartScreen apparaît, cliquez sur Informations complémentaires, puis Exécuter quand même.
  2. Ouvrez Diskshaper depuis le menu Démarrer et appuyez sur Analyser.
  • Lecture seule jusqu’à ce que vous nettoyiez
  • Tout va à la Corbeille
  • En ligne seulement pour vérifier les mises à jour, désactivable
